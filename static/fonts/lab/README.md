# Lab name fonts

Latin subsets of these Google Fonts families, all under the SIL Open Font License 1.1
(https://openfontlicense.org): Inter Tight, Space Grotesk, Unbounded, Orbitron, Oxanium,
Syne, Bricolage Grotesque, Archivo Black, Bebas Neue, Outfit, Sora, Michroma,
Big Shoulders Display, Fredoka. File names match the Appearance options in the Lab screen.
